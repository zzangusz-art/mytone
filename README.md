# 내말투 상담

학부모 통화 녹음 몇 개로 **선생님 본인의 말투**를 측정해 두고, 그 말투로 학부모 상담 글(문자·카톡·통화 대본)을 쓰는 프로그램입니다. 선생님마다 계정이 따로라 여러 교사가 함께 쓸 수 있습니다.

기존 도구와 다른 점은 두 가지입니다. 말투를 "친근하게" 같은 설명이 아니라 **실제로 한 말과 세어 본 빈도**로 전달하고, 쓴 글이 그 측정값에서 얼마나 벗어났는지 **다시 재서 점수로 보여 줍니다**.

## 화면 먼저 보기(체험판)

https://zzangusz-art.github.io/mytone-preview/ — 설치 없이 화면을 눌러볼 수 있습니다. 가상의 교사·학생 샘플 데이터이고, 녹음 올리기와 직접 적은 메모로 글쓰기는 설치본에서만 동작합니다. 체험판을 다시 만들어 올릴 때는 `3_PUBLISH_PREVIEW.bat`을 씁니다.

## 처음 한 번

1. `0_SETUP.bat` 실행 — 가상환경, 패키지, 음성 인식 모델(약 570MB)을 준비합니다. 여러 번 실행해도 됩니다.
2. `1_RUN.bat` 실행 — 브라우저에서 http://127.0.0.1:8700 이 열립니다.

필요한 것: Windows, Python 3.10 이상, ffmpeg 8 이상(whisper 필터 포함 빌드. `winget install Gyan.FFmpeg`).

## 쓰는 순서

1. **가입** — 아이디, 숫자 PIN, 이름, 역할(담임·교과·학원 강사·원장 등).
2. **① 내 말투 등록** — 통화 녹음 3개 정도를 올립니다. 글로 옮겨지면 「전사 확인·화자 수정」에서 선생님/학부모 구분이 맞는지 봅니다. 노란 줄이 자동 추정이 불확실한 문장이고, 이름표를 누르면 바뀝니다. 이미 글로 된 통화 기록(클로바노트 등)은 붙여넣기로 넣을 수 있습니다.
3. **「내 말투 분석하기」** → **② 말투 카드**에서 측정 결과를 확인합니다. 꼭 쓰는 말·절대 안 쓰는 말을 직접 덧붙일 수 있습니다.
4. **③ 상담 글 만들기** — 학생 이름과 전할 내용 메모를 적으면 그 말투로 1~3안을 씁니다. 안마다 「내 말투 일치도」와 AI 티 표현이 표시됩니다.
5. 마음에 들게 고친 글은 **「이 글로 확정」** — 다음 글부터 그 글을 가장 믿을 만한 기준으로 씁니다. 쓸수록 본인 글에 가까워집니다.

녹음 여러 개를 명령줄로 한 번에 처리할 수도 있습니다(화면과 같은 데이터에 저장됩니다).

```
"%LOCALAPPDATA%\MyTone\venv\Scripts\python.exe" -X utf8 scripts\analyze_cli.py --login 아이디 --name 이름 --pin 1234 통화1.m4a 통화2.m4a 통화3.m4a
```

## Claude 키 연결

`.env.example`을 `.env`로 복사하고 `ANTHROPIC_API_KEY=`에 키를 넣은 뒤 다시 실행하면 화면 오른쪽 위가 「글쓰기: Claude」로 바뀝니다. 키는 서버에만 있고 브라우저로 내려가지 않습니다.

키가 없으면 데모 모드입니다. 이때도 음성 인식, 화자 구분, 말투 측정, 일치도 점검은 전부 동작하고, 글쓰기만 임시 결과가 나옵니다. **② 말투 카드의 「내 말투 프롬프트 복사」**를 Claude·ChatGPT의 지침란에 붙이면 키 없이도 같은 말투로 글을 받을 수 있습니다.

## 여러 교사가 쓰게 하려면

- 계정별로 데이터 폴더가 분리되어 있어 다른 교사의 통화·말투 카드에는 접근할 수 없습니다.
- 한 PC를 서버로 두고 여럿이 접속하려면 `.env`에 `HOST=0.0.0.0`과 `INVITE_CODE=`를 함께 넣습니다(초대 코드 없이는 가입 불가). 인터넷에 공개할 때는 반드시 HTTPS 뒤에 두세요. PIN과 통화 내용이 오갑니다.
- 교사 PC마다 설치할 필요가 없도록 서버 한 곳에 올리는 구성을 권장합니다(아래 "앱 제어 정책" 참고).

## 구조

| 파일 | 하는 일 |
|---|---|
| `app/stt.py` | 음성 → 글. ffmpeg 내장 whisper(whisper.cpp)로 PC 안에서 처리 |
| `app/speakers.py` | 선생님/학부모 발화 구분(호칭·내용 단서 + 대화 흐름) |
| `app/pii.py` | 전화번호·주민번호·학생 이름 가리기 |
| `app/style_stats.py` | 말투 측정: 문장 끝 비율, 말머리, 맞장구, 부탁 표현, 호칭, 입에 붙은 구절 |
| `app/profile.py` | 말투 프로필 = 측정값 + 실제 발화 예시 + (키 있으면) 말하는 방식 분석 |
| `app/prompts.py` | 대필 프롬프트. 설계 이유가 파일 맨 위에 적혀 있습니다 |
| `app/generate.py` | 글 생성, 측정값과 어긋나면 한 번 고쳐 쓰기 |
| `app/aicheck.py` | AI 티 표현 찾기, 내 말투 일치도 |
| `app/llm.py` | Claude 연동(공식 SDK) |
| `app/main.py`, `web/index.html` | 서버와 화면 |
| `scripts/selftest.py` | 전체 흐름 자체 점검(`2_SELFTEST.bat`) |
| `scripts/build_preview.py` | 체험판(정적 한 장) 만들기 |

데이터는 `data/teachers/<교사ID>/`에 JSON으로 저장됩니다. 모델과 가상환경은 `%LOCALAPPDATA%\MyTone\`에 있어서 이 폴더를 옮겨도 다시 받지 않습니다.

## 개인정보

- 녹음은 이 서버 안에서만 글로 옮기고, 옮긴 뒤 원본 음성 파일을 지웁니다(`KEEP_AUDIO=1`로 바꾸지 않는 한).
- 말투 분석에는 선생님 발화만 쓰고, 학생 이름은 `{학생}`으로 가립니다.
- Claude를 연결하면 **가려진 선생님 발화 예시**와 **글 만들 때 적은 메모(학생 이름 포함)**가 Anthropic API로 전송됩니다. 통화 원본과 학부모 발화는 전송되지 않습니다. 단 「Claude로 화자 다시 확인」을 누르면 그 통화의 전사 전체가 전송됩니다.
- 설정에서 계정을 삭제하면 그 교사의 전사·말투 카드·확정한 글이 모두 지워집니다.

여러 교사에게 서비스로 제공하기 전에 확인할 것: 개인정보 처리방침과 처리위탁·국외 이전 고지, 학교 소속 교사의 경우 학교·교육청 정보보안 지침, 통화 상대(학부모)의 음성·발언이 개인정보라는 점. 본인이 참여한 통화의 녹음 자체는 통신비밀보호법 위반이 아니지만, 그 내용을 제3자(서비스 운영자)가 처리하는 것은 개인정보보호법의 문제입니다. 출시 전 변호사 검토를 한 번 받으세요.

## 알아둘 한계

- 화자 구분은 자동 추정입니다. 가상 통화 3건에서 문장 기준 95% 정도였고, 실제 통화(말 겹침·잡음)에서는 더 낮을 수 있어 화면 확인 단계를 두었습니다.
- 음성 인식은 "어…", "음…" 같은 순수 추임새를 일부 지웁니다. 그래서 말투는 종결어미·말머리·호칭·습관 구절 위주로 잡힙니다.
- 「내 말투 일치도」는 측정값과 얼마나 닮았는지를 보는 참고 지표이지, 글의 좋고 나쁨을 판정하지 않습니다.
- 통화가 짧으면 비율이 출렁입니다. 말투 카드의 「자료량」을 확인하세요.

## 문제 해결

- **"애플리케이션 제어 정책에서 이 파일을 차단했습니다"** — Windows 11의 Smart App Control이 새 버전의 파이썬 네이티브 모듈을 막는 경우입니다. `requirements.txt`에 통과가 확인된 버전을 고정해 두었습니다. 다른 PC에서 또 막히면 그 PC에 설치하지 말고 서버 한 곳에 올려 브라우저로 접속하게 하세요.
- **음성 인식 미준비** — `0_SETUP.bat`을 다시 실행하거나, `ffmpeg -filters` 출력에 `whisper`가 있는지 확인하세요.
- **전사가 느림** — 그래픽카드가 없으면 통화 길이의 절반~같은 시간이 걸릴 수 있습니다.
